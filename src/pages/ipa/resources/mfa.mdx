## Show a device login waiting for 2FA  {{ tag: 'GET' , label: '/api/mfa/peer-login' }}

<Row>
  <Col>

              </Col>

## Approve a device login with a 2FA code  {{ tag: 'POST' , label: '/api/mfa/peer-login/approve' }}

<Row>
  <Col>
    Checks the code with the same verifier and lockout as the dashboard 2FA challenge. Repeating an approval that already happened succeeds without a code, so the body and the code are optional; on a login not yet approved, a missing code is a wrong code. The body is at most 1 KiB.
            
    ### Request-Body Parameters
    
    <Properties><Property name="code" type="string" required={false}>
        
            A TOTP code or a backup code. Optional when repeating an approval that already happened.
        
        </Property>
    </Properties>

    
       </Col>

  <Col sticky>
    <CodeGroup title="Request" tag="POST" label="/api/mfa/peer-login/approve">
```bash {{ title: 'cURL' }}
curl -X POST https://management.example.com/api/mfa/peer-login/approve \
-H 'Accept: application/json' \
-H 'Content-Type: application/json' \
-H 'Authorization: Token <TOKEN>' \
--data-raw '{
  "code": "123456"
}'
```

```js
const axios = require('axios');
let data = JSON.stringify({
  "code": "123456"
});
let config = {

  },  
  data : data
};

.then((response) => {
  console.log(JSON.stringify(response.data));
})
.catch((error) => {
  console.log(error);
});
```
