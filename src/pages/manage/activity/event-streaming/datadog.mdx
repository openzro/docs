# Stream Activity Events to Datadog

openZro sends [audit events](/manage/activity) to the
[Datadog Logs Intake API](https://docs.datadoghq.com/api/latest/logs/#send-logs). The events appear in the
[Datadog Log Explorer](https://docs.datadoghq.com/logs/explorer/), where you can search, filter and alert on them, and
use them in Datadog Cloud SIEM.

## Prerequisites

- A Datadog account with permission to create API keys.

## Create a Datadog API key

1. In Datadog, go to **Organization Settings → API Keys**.
2. Click **+ New Key** and give it a descriptive name, such as `openZro Event Streaming`.
3. Click **Create Key** and copy the key.

## Add the exporter in openZro

1. In the openZro dashboard, go to **System → Integrations** and open the **Activity Streamer** tab.
2. Click **Add exporter**.
3. Fill in the dialog:
   - **Name**: a label, for example `Datadog prod`.
   - **Type**: **Datadog Logs Intake**.
   - **Site**: your [Datadog site](https://docs.datadoghq.com/getting_started/site/): US1, US3, US5, EU1 or AP1.
   - **API key**: the key you created.
   - **Service** and **Tags** (optional): the `service` value (default `openzro`) and extra tags such as
     `env:prod,team:secops`.
   - **URL override** (optional): only if you send logs through a proxy or forwarder.
4. Click **Create exporter**.

## Verify

Make a change in the dashboard, for example rename a peer. Within a few seconds the event appears in the Datadog Log
Explorer with `service:openzro` (or the service you set). The `hostname` of each event is the openZro account ID, which
separates accounts when several send to the same Datadog organization.

## Configure with environment variables

To stream the events of every account, set these on the management server instead:

| Variable | Description |
|---|---|
| `OPENZRO_ACTIVITY_EXPORT_DATADOG_API_KEY` | Datadog API key. Enables the exporter. |
| `OPENZRO_ACTIVITY_EXPORT_DATADOG_SITE` | `us1`, `us3`, `us5`, `eu1` or `ap1`. |
| `OPENZRO_ACTIVITY_EXPORT_DATADOG_URL` | Intake URL override, without the path. |
| `OPENZRO_ACTIVITY_EXPORT_DATADOG_SERVICE` | `service` value (default `openzro`). |
| `OPENZRO_ACTIVITY_EXPORT_DATADOG_SOURCE` | `ddsource` value (default `openzro`). |
| `OPENZRO_ACTIVITY_EXPORT_DATADOG_TAGS` | Extra tags, e.g. `env:prod,team:security`. |
| `OPENZRO_ACTIVITY_EXPORT_DATADOG_HOSTNAME` | `hostname` value (default: the account ID). |
| `OPENZRO_ACTIVITY_EXPORT_DATADOG_BATCH_SIZE` | Events per request (default `100`). |
| `OPENZRO_ACTIVITY_EXPORT_DATADOG_FLUSH_INTERVAL` | Maximum time between requests (default `5s`). |
| `OPENZRO_ACTIVITY_EXPORT_DATADOG_BUFFER_SIZE` | Events queued in memory (default `10000`). |
