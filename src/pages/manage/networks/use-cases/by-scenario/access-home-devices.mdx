# Access Home Devices (VPN-to-Site)

This guide shows how to access your home network devices from anywhere using the Networks feature.

## What You'll Achieve

After following this guide, you'll be able to access your home NAS, media server, home automation, or any device on your home network from your laptop or phone—anywhere in the world.

```
Your Laptop ──────► openZro Tunnel ──────► Routing Peer ──────► Home NAS
  (peer)                                    (at home)           (no openZro)
```

## Prerequisites

- An [openZro instance](/selfhosted/selfhosted-quickstart) (openZro is self-hosted only)
- openZro installed on your laptop or phone ([installation guide](/get-started/install))
- An always-on device at home to serve as the routing peer (Raspberry Pi, NAS with Docker, old laptop, etc.)

## Step 1: Connect Your Laptop to openZro

If you haven't already, [install openZro](/get-started/install) on your laptop and connect:

1. Run the application and click **Connect** in the system tray, or run
   `openzro up --management-url https://<your-management-domain>`
2. Sign in with your account in the browser
3. Verify your device appears under **Peers** in your openZro dashboard

## Step 2: Add Your Laptop to a User Group

1. In **Peers**, open your laptop peer
2. Under **Assigned Groups**, add a new group: `home-users`

    <img src="/docs-static/img/manage/access-control/associate-peer-groups.png" alt="Assigned Groups on the peer page" className="imagewrapper-big"/>

## Step 3: Find Your Home Subnet

Before configuring openZro, identify your home network's subnet.

**On your routing peer device, run:**

```bash
# Linux
ip route | grep -E "^[0-9]"

# macOS
netstat -rn | grep default
```

Look for your local subnet, typically something like `192.168.1.0/24` or `192.168.0.0/24`.

## Step 4: Create a Network for Your Home LAN

1. Go to **Networks** in the openZro dashboard
2. Click **Add Network**
3. Name it `Home LAN` and click **Add Network**

## Step 5: Add Your Home Subnet as a Resource

1. In your new network, on the **Resources** tab, click **Add Resource**
2. Enter a name like `Home Subnet`
3. Enter your home subnet (e.g., `192.168.1.0/24`) as the **Address**
4. Under **Destination Groups**, create a group called `home-lan`
5. Click **Add Resource**

<Note>
For more granular access, add specific device IPs instead of the entire subnet. For example, add `192.168.1.50` to only allow access to your NAS.
</Note>

## Step 6: Create an Access Policy

1. Click **Add Policy** on the `Home Subnet` row. The destination is already `home-lan`.
2. Set **Source** to `home-users` and **Protocol** to `ALL`
3. Click **Continue** twice, name it `Home LAN Access`, and click **Add Policy**

## Step 7: Set Up the Routing Peer

The routing peer forwards traffic from openZro to your local network. Use any always-on Linux device, such as a
Raspberry Pi or a home server.

**Install openZro on your routing peer:**

1. In the openZro dashboard, go to **Setup Keys**
2. Create a new setup key (one-off is recommended). Add `home-routers` to **Auto-assigned groups** and click
   **Create Setup Key**.

<Note>
Use a group of its own for the routing peer instead of `home-lan`. The `home-lan` group is the policy destination, so
putting the routing peer in it would also give `home-users` access to the routing peer itself.
</Note>

3. On your routing peer, run:

```bash
# See /get-started/install for distro-specific instructions; quick one-liner for Debian/Ubuntu:
curl -fsSL https://pkg.openzro.io/openzro-archive-keyring.gpg | sudo tee /usr/share/keyrings/openzro-archive-keyring.gpg > /dev/null && echo "deb [signed-by=/usr/share/keyrings/openzro-archive-keyring.gpg] https://pkg.openzro.io/apt stable main" | sudo tee /etc/apt/sources.list.d/openzro.list > /dev/null && sudo apt-get update && sudo apt-get install -y openzro
sudo openzro up --setup-key YOUR_SETUP_KEY --management-url https://<your-management-domain>
```

4. In the `Home LAN` network, open the **Routing Peers** tab and click **Add Routing Peer**
5. Choose **Peer Group**, select `home-routers`, click **Continue** and then **Add Routing Peer**

Your home network is now set up:

    <img src="/docs-static/img/manage/networks/use-cases/by-scenario/access-home-devices/home-lan-network.png" alt="Home LAN network with the home subnet resource" className="imagewrapper-big"/>

## Step 8: Test the Connection

From your laptop (connected to a different network like mobile data or coffee shop WiFi):

```bash
ping 192.168.1.1  # Your router
ping 192.168.1.50 # Your NAS or other device
```

You can now access your home devices from anywhere.

## Common Home Devices to Access

| Device | Typical Access Method |
|--------|----------------------|
| Synology/QNAP NAS | Web UI (port 5000/5001), SMB shares |
| Home Assistant | Web UI (port 8123) |
| Plex/Jellyfin | Web UI (port 32400/8096) |
| Pi-hole | Web UI (port 80), DNS (port 53) |
| Security cameras | RTSP streams, web interfaces |
| Printers | IPP/AirPrint, web interfaces |

## Troubleshooting

**Can't reach home devices:**
1. Verify the routing peer is online: check `openzro status` on the routing peer
2. Ensure the routing peer can reach local devices: `ping 192.168.1.1` from the routing peer
3. Check that your access policy includes your user/device

**Intermittent connectivity:**
1. Ensure the routing peer has a stable internet connection
2. Check whether your network blocks UDP; openZro falls back to relayed connections, which work over TCP/WebSocket but are slower
