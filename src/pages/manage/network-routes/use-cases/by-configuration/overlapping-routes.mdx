# Resolving Overlapping Routes

openZro [Network Routes](/manage/network-routes) enable peers to access external networks such as VPCs, LANs, or office networks. When multiple networks have overlapping IP ranges, openZro's route selection feature lets you choose which routes to apply on the client side.

## Using Route Selection

You can select routes through the CLI or the system tray GUI.

### CLI

List available networks (`openzro routes` still works as an alias of `openzro networks`):

```bash
openzro networks list
```

Example output:

```
Available Networks:

  - ID: aws-vpc-ireland
    Network: 172.17.0.0/16
    Status: Selected

  - ID: aws-vpc-ohio
    Network: 172.17.0.0/16
    Status: Selected
```

In this example, both routes have the same network range and are both selected, causing a conflict. To resolve this, select only one route:

```bash
openzro networks select aws-vpc-ireland
```

<Note>
    Running `openzro networks select` replaces the current selection by default. Use `-a` to append instead.
</Note>

Additional examples:

```bash
# Select all routes
openzro networks select all

# Select multiple routes
openzro networks select route1 route2

# Append a route without deselecting others
openzro networks select -a route3
```

### GUI

Open the openZro tray menu and click **Networks**. The window has three tabs: **All networks**, **Overlapping
networks** and **Exit-node networks**. Use the checkbox next to each route to select or deselect it, or the
**Select all** and **Deselect All** buttons.

### Enabling All Routes

Use `openzro networks select all` in the CLI or the corresponding button in the GUI to select all available routes, including any added in the future. This restores the default behavior.

### Disabling All Routes

Use `openzro networks deselect all` in the CLI or the GUI button to deselect all routes, including any added in the future.
