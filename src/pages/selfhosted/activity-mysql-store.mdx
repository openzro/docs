# Activity Events MySQL store

## Using MySQL for fresh installations

To enable MySQL add to your management service the following environmental variable:
```bash
OZ_ACTIVITY_EVENT_STORE_ENGINE=mysql
OZ_ACTIVITY_EVENT_MYSQL_DSN="<username>:<password>@tcp(<host>:<port>)/<db_name>?parseTime=true"
```

You can switch back to sqlite storage by setting the `OZ_ACTIVITY_EVENT_STORE_ENGINE` variable to `sqlite`.

<Note>
    The `docker-compose.yml` generated by `configure.sh` does not pass these variables. Add them to the `environment`
    section of the `management` service, and add them again if you regenerate the file.
</Note>

<Note>
    Switching between storage options requires migration steps to prevent data loss.
</Note>
