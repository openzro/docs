# Environment Variables Configuration

This page provides a comprehensive reference for all environment variables available when self-hosting openZro. Environment variables allow you to configure the Management Server, Signal Server, Relay Server (including the embedded STUN server), and Dashboard services.

<Note>
Environment variables set in your `setup.env` file are used by the `configure.sh` script to generate the final configuration files. Changes to `setup.env` require re-running `./configure.sh` to take effect.
</Note>

## Overview

openZro uses two types of environment variables:

1. **Setup Variables** (`OPENZRO_` prefix) - Used in docker-compose templates and `setup.env` for initial configuration
2. **Runtime Variables** (`OZ_` prefix) - Can override CLI flags at runtime using the pattern `--flag-name` → `OZ_FLAG_NAME`

## Core Setup Variables

These variables are set in your `setup.env` file before running the configuration script.

### Domain and Network

| Variable | Description | Example |
|----------|-------------|---------|
| `OPENZRO_DOMAIN` | Your openZro domain name | `openzro.example.com` |
| `OPENZRO_LETSENCRYPT_EMAIL` | Email for Let's Encrypt certificates | `admin@example.com` |
| `OPENZRO_DISABLE_LETSENCRYPT` | Disable automatic Let's Encrypt | `true` |

### Port Configuration

| Variable | Default | Description |
|----------|---------|-------------|
| `OPENZRO_MGMT_API_PORT` | `33073` | Management API port |
| `OPENZRO_SIGNAL_PORT` | `10000` | Signal server port |
| `OPENZRO_RELAY_PORT` | `33080` | Relay server port |
| `NGINX_SSL_PORT` | `443` | Dashboard HTTPS port |

### STUN Configuration

<Note>
The default quickstart deployment uses the relay service's embedded STUN server. The variables below configure STUN functionality within the relay container via `relay.env`.
</Note>

| Variable | Default | Description |
|----------|---------|-------------|
| `OZ_ENABLE_STUN` | `true` | Enable embedded STUN server in relay |
| `OZ_STUN_PORTS` | `3478` | STUN server UDP ports |
| `OZ_STUN_LOG_LEVEL` | `info` | STUN server log level |

## Management Server Variables

### Database Configuration

| Variable | Default | Description |
|----------|---------|-------------|
| `OPENZRO_STORE_CONFIG_ENGINE` | `sqlite` | Store engine: `sqlite`, `postgres`, or `mysql` |
| `OPENZRO_STORE_ENGINE_POSTGRES_DSN` | - | PostgreSQL connection string |
| `OPENZRO_STORE_ENGINE_MYSQL_DSN` | - | MySQL connection string |
| `OPENZRO_DATASTORE_ENC_KEY` | Auto-generated | Encryption key for sensitive data |

<Note>
See [Management Postgres Store](/selfhosted/postgres-store) for PostgreSQL setup details.
</Note>

### Single Account Mode

| Variable | Default | Description |
|----------|---------|-------------|
| `OPENZRO_MGMT_SINGLE_ACCOUNT_MODE_DOMAIN` | - | Domain for single account mode |

<Note>
openZro runs in single account mode by default since v0.10.1. All users joining your self-hosted instance will be part of the same account/network.
</Note>

### Relay Configuration

| Variable | Description |
|----------|-------------|
| `OPENZRO_RELAY_ENDPOINT` | Relay server endpoint URL |
| `OPENZRO_RELAY_AUTH_SECRET` | Shared authentication secret for relay |

### Signal Configuration

| Variable | Description |
|----------|-------------|
| `OPENZRO_SIGNAL_PROTOCOL` | Protocol: `http` or `https` |

### DNS Configuration

| Variable | Default | Description |
|----------|---------|-------------|
| `OPENZRO_MGMT_DNS_DOMAIN` | `openzro.selfhosted` | DNS domain for peer resolution |

### TLS/Certificates

| Variable | Description |
|----------|-------------|
| `OPENZRO_MGMT_API_CERT_FILE` | Path to TLS certificate file |
| `OPENZRO_MGMT_API_CERT_KEY_FILE` | Path to TLS certificate key file |

### Metrics and Analytics

| Variable | Default | Description |
|----------|---------|-------------|
| `OPENZRO_DISABLE_ANONYMOUS_METRICS` | `false` | Disable anonymous usage metrics |

## Runtime Environment Variables (OZ_ prefix)

These variables can override CLI flags at runtime. The naming convention is `OZ_<FLAG_NAME>` where the flag name is uppercased and hyphens are replaced with underscores.

### Management Server Runtime

| Variable | Description |
|----------|-------------|
| `OZ_PORT` | Server port (overrides `--port`) |
| `OZ_DATADIR` | Data directory (overrides `--datadir`) |
| `OZ_CONFIG` | Config file path (overrides `--config`) |
| `OZ_LOG_LEVEL` | Log level: `debug`, `info`, `warn`, `error` |
| `OZ_LOG_FILE` | Log file path |
| `OZ_METRICS_PORT` | Prometheus metrics port |
| `OZ_LETSENCRYPT_DOMAIN` | Let's Encrypt domain |
| `OZ_CERT_FILE` | TLS certificate file |
| `OZ_CERT_KEY` | TLS certificate key file |
| `OZ_DNS_DOMAIN` | DNS domain for peers |
| `OZ_DISABLE_GEOLITE_UPDATE` | Disable GeoLite database updates |

### Advanced Runtime Variables

| Variable | Description |
|----------|-------------|
| `OZ_EVENT_ACTIVITY_LOG_ENABLED` | Enable activity log events |
| `OZ_GET_ACCOUNT_BUFFER_INTERVAL` | Account buffer interval duration |
| `OZ_SQL_MAX_OPEN_CONNS` | Maximum SQL database connections |
| `OZ_STORE_TRANSACTION_TIMEOUT` | Store transaction timeout |
| `OZ_API_RATE_LIMITING_ENABLED` | Enable API rate limiting |
| `OZ_API_RATE_LIMITING_RPM` | Rate limit requests per minute |
| `OZ_API_RATE_LIMITING_BURST` | Rate limit burst size |
| `OPENZRO_METRICS_INTERVAL_IN_SECONDS` | Metrics push interval |

## Coturn (TURN Server) Variables (Legacy)

<Note>
The default quickstart deployment no longer uses a separate Coturn container. STUN functionality is now embedded in the relay service. The variables below are only relevant for legacy deployments or advanced configurations that still use Coturn.
</Note>

Coturn configuration is generated from templates using these variables:

| Variable | Default | Description |
|----------|---------|-------------|
| `TURN_DOMAIN` | - | TURN server domain |
| `TURN_USER` | - | TURN username |
| `TURN_PASSWORD` | - | TURN password |
| `TURN_MIN_PORT` | `49152` | Minimum relay port |
| `TURN_MAX_PORT` | `65535` | Maximum relay port |
| `TURN_EXTERNAL_IP_CONFIG` | - | External IP configuration |

The Coturn service uses static ports: `3478` (STUN/TURN) and `5349` (TLS TURN).

## Configuration Examples

### Basic Setup

```bash
# setup.env
OPENZRO_DOMAIN="openzro.example.com"
OPENZRO_LETSENCRYPT_EMAIL="admin@example.com"
```

### PostgreSQL Database

```bash
# setup.env
OPENZRO_STORE_CONFIG_ENGINE="postgres"
OPENZRO_STORE_ENGINE_POSTGRES_DSN="postgres://user:password@localhost:5432/openzro?sslmode=disable"
```

### Custom Ports (Behind Reverse Proxy)

```bash
# setup.env
OPENZRO_DOMAIN="openzro.example.com"
OPENZRO_DISABLE_LETSENCRYPT="true"
OPENZRO_MGMT_API_PORT="443"
OPENZRO_SIGNAL_PORT="443"
```

### Disable Anonymous Metrics

```bash
# setup.env
OPENZRO_DISABLE_ANONYMOUS_METRICS="true"
```

### Enable API Rate Limiting

Set these in your container environment or docker-compose:

```yaml
environment:
  - OZ_API_RATE_LIMITING_ENABLED=true
  - OZ_API_RATE_LIMITING_RPM=60
  - OZ_API_RATE_LIMITING_BURST=10
```

## Variable Precedence

Configuration values are applied in the following order (later values override earlier):

1. Default values
2. Configuration file (`config.yaml` for combined setup, `management.json` for older multi-container setup)
3. Environment variables
4. Command-line flags
