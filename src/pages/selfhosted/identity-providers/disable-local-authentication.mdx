# Disable Local Authentication

If you prefer to delegate all credential storage and authentication to your identity provider, you can turn off local
(email/password) sign-in in the bundled Dex. All users then sign in through an
[external identity provider](/selfhosted/identity-providers).

This is useful when you want to:

- Enforce that all users authenticate via external identity providers only
- Centralize credential management and password policies in your IdP
- Remove the bootstrap administrator account once SSO works

## Before you start

<Warning>
openZro does not check whether another administrator can still sign in. If you disable local sign-in before an
external identity provider works and one of its users has the Owner or Admin role, nobody can sign in to the dashboard.
</Warning>

1. Add and test at least one external identity provider (see [Identity Providers](/selfhosted/identity-providers)).
2. Sign in with an external account, then, as the bootstrap administrator, give that user the **Owner** role (transfer
   ownership) or the **Admin** role under **Identity → Users & Groups**.
3. Sign in again with the external account and check that you can open **Settings**.

<Note>
Local users provisioned over [SCIM](/manage/team/idp-sync/scim-local-users) also sign in with Dex passwords. Turning
off the password database stops them from signing in too.
</Note>

## Disable local sign-in

Local sign-in is controlled by Dex's configuration:

- `enablePasswordDB` turns the email/password login form on or off;
- `staticPasswords` holds the bootstrap administrator account.

### Docker Compose

1. Edit `artifacts/dex.config.yaml`: set `enablePasswordDB: false` and remove the `staticPasswords` block.
2. Restart Dex:
   ```bash
   cd artifacts
   docker compose restart dex
   ```

`configure.sh` regenerates `dex.config.yaml` from its template on every run, which turns local sign-in back on. Repeat
the edit after re-running it.

### Kubernetes (Helm)

Set the same values in your chart values and upgrade:

```yaml
dex:
  config:
    enablePasswordDB: false
    staticPasswords: []
```

## Re-enable local sign-in

Set `enablePasswordDB: true` again and restore the `staticPasswords` entry (on Docker Compose, re-running
`configure.sh` does this), then restart Dex. This is also the recovery path if no external account can sign in.
