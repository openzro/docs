# Upgrade Your Self-Hosted openZro Installation

## Check Release Notes

Before upgrading, review the [release notes](https://github.com/openzro/openzro/releases) for breaking changes or
migration steps. The dashboard, management, signal and relay are built from the same repository and released together
with the same version number.

## Upgrade Steps

1. Run the [backup](/selfhosted/maintenance/backup) steps.
2. Review the release notes for breaking changes.
3. Pull the new images. If you pinned versions with the `OPENZRO_*_TAG` variables in `setup.env`, update them and
   re-run `./configure.sh` first (see the note below).
    ```bash
    cd artifacts
    docker compose pull management dashboard signal relay
    ```
4. Recreate the containers with the new images:
    ```bash
    docker compose up -d --force-recreate management dashboard signal relay
    ```

<Note>
Before re-running `configure.sh`, copy `artifacts/management.json` to the `infrastructure_files` directory so the
datastore encryption key is kept ([openzro#247](https://github.com/openzro/openzro/issues/247)).
</Note>

Dex and Coturn use upstream images; upgrade them the same way when you change `OPENZRO_DEX_TAG` or `COTURN_TAG`.
