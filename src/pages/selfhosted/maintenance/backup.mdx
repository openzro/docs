# Back Up Your Self-Hosted openZro Installation

To back up an openZro installation, copy the generated configuration files and the data of the Management service and
the embedded Dex.

The configuration files are in the `artifacts/` directory that `configure.sh` created. Copy them, together with your
`setup.env`, to a backup location:
```bash
cd openzro/infrastructure_files
mkdir -p backup
cp setup.env backup/
cp -r artifacts/docker-compose.yml artifacts/management.json artifacts/dex.config.yaml \
  artifacts/turnserver.conf artifacts/grpc-certs backup/
```

`management.json` holds the `DataStoreEncryptionKey`. Without it, the encrypted fields in the database cannot be read,
so keep it with the database backup.

<Note>
For detailed information about each configuration file, see the [Configuration Files Reference](/selfhosted/configuration-files).
</Note>

To save the databases, stop the services and copy their data directories:
```bash
cd artifacts
docker compose stop management dex
docker compose cp -a management:/var/lib/openzro/ ../backup/management/
docker compose cp -a dex:/var/lib/dex/ ../backup/dex/
docker compose start management dex
```

If you use PostgreSQL or MySQL for the management store, back up that database with its own tools (`pg_dump`,
`mysqldump`) instead of, or in addition to, the data directory.
