# Remove Your Self-Hosted openZro Installation

To remove the openZro installation and all related data from your server, run these commands from the
`infrastructure_files` directory where you ran `configure.sh`:
```bash
cd artifacts
# remove all openZro containers and volumes (data)
docker compose down --volumes
cd ..
# remove the generated configuration files
rm -rf artifacts
```

`setup.env` is left in place; delete it too if you don't need it.
