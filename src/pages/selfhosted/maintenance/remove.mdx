# Remove Your Self-Hosted openZro Installation

To remove the openZro installation and all related data from your server, run these commands from the folder where you installed openZro:
```bash
# remove all openZro-related containers and volumes (data)
docker compose down --volumes
# remove downloaded and generated config files
rm -f docker-compose.yml dashboard.env config.yaml nginx-openzro.conf caddyfile-openzro.txt npm-advanced-config.txt
```
