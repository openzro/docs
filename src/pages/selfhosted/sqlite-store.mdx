# Management SQLite store

SQLite is the default storage engine for the openZro Management service. It needs no external database and works out
of the box. The data lives in `store.db` in the management data directory (`/var/lib/openzro/` in the container).

<Note>
If you need concurrent access or several management instances for high availability, use
[PostgreSQL](/selfhosted/postgres-store) instead. MySQL is also supported: set `OPENZRO_STORE_CONFIG_ENGINE=mysql` and
`OPENZRO_STORE_ENGINE_MYSQL_DSN` (format `user:password@tcp(host:3306)/database`) in `setup.env`.
</Note>

## Configuration

SQLite is the default. To set it explicitly, add this to your `setup.env` and re-run `./configure.sh`:
```bash
OPENZRO_STORE_CONFIG_ENGINE=sqlite
```
This sets the following in your `management.json`:
```json
    "StoreConfig": {
        "Engine": "sqlite"
    }
```

Confirm SQLite is active by checking the management logs on startup:
```bash
docker compose logs management
```
You should see:
```
INFO management/server/store/store.go:357: using SQLite store engine
```

## Migrating from JSON store to SQLite store

Very old deployments kept their data in a `store.json` file. If the management service starts with no store engine
configured and finds a `store.json`, it migrates it to SQLite automatically. You can also run the migration by hand
with the `sqlite-migration upgrade` subcommand, which is part of the management binary in the official image.

<Note>
    The following commands assume Docker with the compose plugin. If you have the standalone docker-compose, use
    `docker-compose` instead.
</Note>

1. In the directory that contains your `docker-compose.yml` and `management.json`, stop the Management service:
```bash
docker compose stop management
```
2. Back up the data directory (`store.json` is in `/var/lib/openzro/`):
```bash
mkdir backup
docker compose cp -a management:/var/lib/openzro/ backup/
```
3. Run the migration:
```bash
docker compose run --rm --entrypoint /go/bin/openzro-mgmt management \
  sqlite-migration upgrade --datadir /var/lib/openzro/ --log-file console
```
4. Set the `Engine` field to `sqlite` in `management.json`:
```json
    "StoreConfig": {
        "Engine": "sqlite"
    }
```
5. Start the Management service and check the logs for the store engine line shown above:
```bash
docker compose start management
docker compose logs management
```
