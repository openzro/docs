# Windows Installation

The openZro client (agent) connects a device to an openZro deployment. openZro is
self-hosted; if you don't have a deployment yet, see the
[self-hosting quickstart](/selfhosted/selfhosted-quickstart).

1. Download the installer for 64-bit Windows:
   <Button href="https://pkg.openzro.io/windows/openzro.msi" variant="text">openZro MSI installer</Button>.
   Each release's MSI is also on the [releases page](https://github.com/openzro/openzro/releases).
2. Run the installer. It installs the `openzro` CLI, the background service
   (`Openzro`) and the desktop app in `C:\Program Files\Openzro`, and adds the
   CLI to your `PATH`.
3. Continue with [Running openZro with SSO login](#running-open-zro-with-sso-login).

<Note>
    The MSI is not code-signed yet, so Windows SmartScreen may warn on first run.
    Click **More info → Run anyway**. Code signing is in progress.
</Note>

To uninstall the client and the service, use **Settings → Apps → Installed apps**
(or **Programs and Features**).

## Point the client at your deployment

Every client needs your management URL. In the desktop app, open
**Settings → Advanced Settings** from the openZro icon in the system tray and
enter it. With the CLI, pass `--management-url https://<your-management>:443`
to `openzro up`.

## Running openZro with SSO login

### Desktop app
Launch the openZro desktop app and click **Connect**. Your browser opens your
identity provider's sign-in page; once you sign in, the device connects.

### CLI
In a terminal:
```bash
openzro up --management-url https://<your-management>:443
```
Your browser opens your identity provider's sign-in page. When the login
completes, the CLI prints `Connected`.

<Note>
    If your administrator requires [2FA to sign in devices](/manage/settings/multi-factor-authentication#2-fa-on-device-sign-in),
    the client also opens an approval page where you enter a code from your authenticator app.
</Note>

Check the connection:
```bash
openzro status
```

## Running openZro with a setup key

To register a server or another unattended peer, use a
[setup key](/manage/peers/register-machines-using-setup-keys):

```bash
openzro up --management-url https://<your-management>:443 --setup-key <SETUP KEY>
```

If you leave out `--setup-key`, `openzro up` starts the SSO login in your browser
instead.

Check the connection and the tunnel interface:
```bash
openzro status
netsh interface ip show config name="wt0"
```
