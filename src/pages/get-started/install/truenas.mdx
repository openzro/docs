# Install openZro on TrueNAS

<Warning>
    **Not validated yet.** openZro is not in the TrueNAS Apps catalog. The steps
    below run the openZro client image as a TrueNAS **Custom App**; this setup has
    not been tested on TrueNAS yet. Support for TrueNAS is being planned; until
    then, test it before relying on it.
</Warning>

## Run openZro as a Custom App

In TrueNAS SCALE, go to **Apps → Discover Apps → Custom App** and configure:

- **Image**: `ghcr.io/openzro/openzro`, tag `latest` (or a release tag such as
  `0.53.1-alpha.103`).
- **Environment variables**:
  - `OZ_SETUP_KEY`: a [setup key](/manage/peers/register-machines-using-setup-keys)
    from your openZro dashboard.
  - `OZ_MANAGEMENT_URL`: your management server, e.g.
    `https://your-management.example.com:443`. openZro is self-hosted; this must
    point at your own server.
  - `OZ_HOSTNAME` (optional): the name this peer shows in the dashboard, e.g.
    `truenas`.
- **Network**: enable **Host Network**, so the container uses the TrueNAS host's
  network stack. Without it, the container cannot reach your LAN or act as a
  routing peer.
- **Capabilities**: add `NET_ADMIN` (and `SYS_ADMIN`, `SYS_RESOURCE`, as in the
  [Docker guide](/get-started/install/docker)).
- **Storage**: mount a persistent volume at `/var/lib/openzro`, so the peer keeps
  its identity and configuration across restarts.

After the app is **Running**, open **Peers** in your openZro dashboard: the
TrueNAS peer should be listed.

<Note>
    The client runs in a container, so you cannot reach the TrueNAS host's services
    through the peer's openZro IP or domain: that traffic reaches the container. Use
    the routing setup below.
</Note>

## Access TrueNAS via openZro Networks

Because openZro on TrueNAS runs inside a Docker container, you cannot connect directly to the TrueNAS host or its services by IP as you would to a normal peer. To reach TrueNAS or other devices on the same LAN, use [openZro Networks](/manage/networks/homelab/access-home-network):

1. **Create a openZro Network**: In the dashboard, go to **Networks** → **Add Network**. Name it (e.g., "Home LAN" or "TrueNAS LAN").
2. **Add the TrueNAS peer as a routing peer**: In that network, click **Add Routing Peer** and select the TrueNAS peer. This makes TrueNAS the gateway for traffic into your local subnet.
3. **Add a network resource**: Click **Add Resource**. Either:
   - Add your **entire LAN subnet** (e.g., `192.168.1.0/24`) so you can reach TrueNAS and any other device on that subnet, or
   - Add a **single resource** (e.g., `192.168.1.100/32`) if you only need access to the TrueNAS host.

After you define an [access control policy](/manage/networks/homelab/access-home-network#create-an-access-control-policy) that allows the right peers or groups to reach this network, you can access TrueNAS and other resources on that subnet through the TrueNAS routing peer.
