# macOS Installation

The openZro client (agent) connects a device to an openZro deployment. openZro is
self-hosted; if you don't have a deployment yet, see the
[self-hosting quickstart](/selfhosted/selfhosted-quickstart).

## Package install

1. Download the installer. It is universal, for both Intel and Apple Silicon:
   <Button href="https://pkg.openzro.io/macos/openzro.pkg" variant="text" arrow="right">Download openZro for macOS</Button>.
   Each release's `.pkg` is also on the [releases page](https://github.com/openzro/openzro/releases).
2. Open the `.pkg` and follow the steps. The installer is signed with an Apple
   Developer ID and notarized, so macOS opens it without a Gatekeeper warning.
3. It installs:
   - the desktop app, `/Applications/openZro UI.app`;
   - the CLI, `/usr/local/bin/openzro`;
   - the background service, which it registers and starts.
4. Continue with [Running openZro with SSO login](#running-open-zro-with-sso-login).

### Uninstall

```bash
sudo openzro service stop
sudo openzro service uninstall
sudo rm /usr/local/bin/openzro
sudo rm -rf "/Applications/openZro UI.app"
```

## Binary install (CLI only)

1. Pick a version on the [releases page](https://github.com/openzro/openzro/releases)
   and download the macOS archive. `<ARCH>` is `arm64` (Apple Silicon), `amd64`
   (Intel) or `all` (universal):
   ```bash
   curl -L -o openzro.tar.gz https://github.com/openzro/openzro/releases/download/v<VERSION>/openzro_<VERSION>_darwin_<ARCH>.tar.gz
   ```
2. Install the binary:
   ```bash
   tar xzf openzro.tar.gz
   sudo install -m 0755 openzro /usr/local/bin/openzro
   ```
3. Install and start the service:
   ```bash
   sudo openzro service install
   sudo openzro service start
   ```

<Note>
    The raw binary in the archive is not notarized. If macOS blocks it, run
    `xattr -d com.apple.quarantine /usr/local/bin/openzro`. The `.pkg` above does
    not need this.
</Note>

## Point the client at your deployment

Every client needs your management URL. In the desktop app, open
**Settings → Advanced Settings** from the openZro icon in the menu bar and enter
it. With the CLI, pass `--management-url https://<your-management>:443` to
`openzro up`.

## Running openZro with SSO login

### Desktop app
Launch the openZro desktop app and click **Connect**. Your browser opens your
identity provider's sign-in page; once you sign in, the device connects.

### CLI
```bash
openzro up --management-url https://<your-management>:443
```
Your browser opens your identity provider's sign-in page. When the login
completes, the CLI prints `Connected`.

<Note>
    If your administrator requires [2FA to sign in devices](/manage/settings/multi-factor-authentication#2-fa-on-device-sign-in),
    the client also opens an approval page where you enter a code from your authenticator app.
</Note>

Check the connection:
```bash
openzro status
```

## Running openZro with a setup key

To register a server or another unattended peer, use a
[setup key](/manage/peers/register-machines-using-setup-keys):

```bash
openzro up --management-url https://<your-management>:443 --setup-key <SETUP KEY>
```

If you leave out `--setup-key`, `openzro up` starts the SSO login in your browser
instead.

Check the connection and the tunnel interface:
```bash
openzro status
ifconfig utun100
```
