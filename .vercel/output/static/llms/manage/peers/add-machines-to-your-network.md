# Add peers to your openZro network

Whether you have a network for personal use or manage your company's corporate network, you'd probably want to add machines
(or peers in openZro's terms) to your network.

openZro peer is a machine that runs the [openZro agent](/about-openzro/how-openzro-works#client-application)
and is connected to the network. openZro peer can be a virtual machine running in the cloud like AWS or Google Cloud,
an Android or iOS device, a personal laptop, a single-board computer like Raspberry Pi, a docker container, or even a router.

## Use openZro web UI to add new peers

To add a new peer to your network follow these steps:
1. Sign-in to your openZro account at https://your-management.example.com/ and go to the Peers tab.
2. Hit `Add Peer` button

    

3. Follow the instructions

    

4. Refresh the Peers tab, and it will display new machines
