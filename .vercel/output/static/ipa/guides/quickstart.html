    Get openZro

    Quickstart

    This guide will get you all set up and ready to use the openZro API. We'll cover how to get started using cURL and how to make your first API request. We'll also look at where to go next to find all the information you need to take full advantage of our powerful REST API.

    Install cURL

    For this guide, we'll be using cURL to make our first API request. If you don't already have cURL installed, you can download it from the cURL website.

    Get an access token

    Before making your first API request, you need to create an access token to authenticate requests to the API. You can create an access token in the openZro dashboard under Users » Me. After the token was created successfully make sure to store it as we need it for the next step.

    Making your first API request

    After creating your access token, you are ready to make your first call to the openZro API. Below, you can see how to send a GET request to the peers endpoint to get a list of all peers in your network.

    GET
    /api/peers
    curl -X GET https://api.openzro.io/api/peers \
    -H 'Accept: application/json' \
    -H 'Authorization: Token <TOKEN>'

    NOTE: If you are self-hosting openzro, and used the advanced guide, you may need to use port 33073 with your management URL.

    Read the docs for the peers endpoint
